GDH 拡張検索 導入支援 / GDH Search Setup (Windows / Chrome, Edge)

日本語 / English
Windowsの表示言語が日本語の場合は日本語、それ以外は英語で導入を案内します。
Setup automatically uses Japanese for Japanese Windows UI, and English for all other Windows UI languages.

1. 配布ZIPを右クリックし「すべて展開」します。
2. 展開先の Install.bat をダブルクリックします。管理者として実行する必要はありません。
3. 1（Edge）または2（Chrome）を入力します。
4. ブラウザーで「開発者モード」をオンにし、「展開して読み込み」を押します。
5. パス入力欄にCtrl+Vで貼り付け、フォルダーを選択します。
6. GDHの機械情報検索画面を再読み込みし、右下の「拡張検索」を押します。

配置先：%LOCALAPPDATA%\GDH_Search\Extension
初回登録後、このフォルダーを移動・削除しないでください。

更新時も新しい配布ZIPを展開してInstall.batを実行します。
既存ファイルをバックアップして配置します。その後、拡張機能管理画面の再読み込みボタンを押し、GDH画面も再読み込みします。
旧バージョンを別のフォルダーから登録した場合は、古い登録を削除して新しい配置先を登録してください。
バックアップは同じGDH_Searchフォルダー内のBackup-から始まるフォルダーに残ります。

スクリプト実行が会社の設定で禁止されている場合：
BATは導入用PowerShellのプロセスだけ実行を許可し、PCの恒久的な実行ポリシーは変更しません。会社の管理ポリシーが優先され、制限されている場合は手動で導入できます。
edge://extensions/ または chrome://extensions/ を開き、開発者モードをオンにして、同梱のGDH_Search_Extension（manifest.jsonのあるフォルダー）を読み込んでください。
この場合は同梱フォルダーを移動・削除しないでください。

ブラウザーが見つからない場合は、管理画面を手動で開いて表示された配置先を登録してください。
登録や有効化は自動では行いません。管理ポリシー・レジストリ・ブラウザープロファイルは変更しません。
削除する場合は、先にブラウザーの拡張機能管理画面で本拡張機能を削除し、その後に配置先と不要なバックアップを削除してください。

本ツールはNC戦略 吉田が作成したベータ版で、GDHの標準機能ではありません。動作保証はありません。
拡張画面についてはGDHヘルプデスクではなく、NC戦略 吉田までお問い合わせください。


English instructions

1. Extract the entire distribution ZIP (Extract All).
2. Double-click Install.bat. Administrator rights are not required.
3. Enter 1 for Edge or 2 for Chrome.
4. Turn on Developer mode and click Load unpacked in the browser.
5. Paste the copied path with Ctrl+V and select the folder.
6. Reload the GDH machine search page and click the extension search button at the bottom right.

Installation folder: %LOCALAPPDATA%\GDH_Search\Extension
Do not move or delete this folder after loading the extension.

Updates: Extract the new package and run Install.bat again. Previous files are backed up in a Backup-* folder next to Extension. Click Reload on the extension management page, then reload the GDH page.
If the previous extension was loaded from another folder, remove its registration and load the new installation folder.

If scripts are blocked, install manually: open edge://extensions/ or chrome://extensions/, enable Developer mode, and load the included GDH_Search_Extension folder containing manifest.json. Keep that folder in place.
Install.bat uses ExecutionPolicy Bypass only for the setup PowerShell process. It does not change the permanent execution policy. Company-managed restrictions take precedence.
The installer does not change management policies, the registry, or browser profiles. Browser registration and enabling remain manual.
To uninstall, remove the extension in the browser first, then delete the installation folder and any unwanted backups.

To select the setup language manually, run from PowerShell:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1 -Language ja
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1 -Language en
