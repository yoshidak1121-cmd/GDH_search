# CNC機械情報ビューア（v1.3.0）

GDHの機械情報CSVをローカルブラウザで読み込み、約19万件規模の機械情報を検索・詳細確認できる単一HTMLアプリです。

## ブラウザ拡張機能として使う

GitHub Releasesから `GDH_Search_Extension_v1.3.0.zip` を取得して展開し、Chrome / Edgeの拡張機能管理画面から読み込んでください。GDH本体へのファイル設置は不要です。機械情報画面右下の「拡張検索」からCSV取得とAND／OR検索を使用できます。詳細は `EXTENSION_INSTALL.md` を参照してください。

## 起動方法

`index.html` を Microsoft Edge / Google Chrome で開きます。開発サーバー、npm、外部CDNは不要です。

- **現在動作する機能**：「CSVを開く」→ GDHから取得済みのCSVを選択 → 検索・閲覧
- **GDH接続後に動作する機能**：「データ取得」→ GDHの正規CSV出力処理でBlobを取得 → 同一CSVをダウンロード → 検索元データへ自動反映

ブラウザ標準のセキュリティ制約のため、独立したローカルHTMLからGDHサイトの確認ダイアログを勝手に押したり、別サイトのCSVダウンロード内容を読み取ることはできません。提供された画面HTMLでCSV出力のPOST先を確認し、`gdh-export.js` に実装しました。GDH本番での動作と画面の正式な配置方法は未確認です。GDH連携は `window.GDH_CSV_EXPORT_ADAPTER` を通じて実装する契約です。

## 入力CSVの実測構成（2026-11-02のユーザー提供CSV）

- 192,836行 / 33列 / 約57MB
- UTF-8 BOM付き
- ヘッダー: NCシリアル番号、NCシリーズ名、NCシステム型名、工作機械シリアル番号、工作機械モデル番号、機械メーカー、サービス拠点、契約番号、契約タイプ、契約期間（月）、契約開始日、契約終了日、契約元拠点、契約者名、販売日、販売会社、機械代理店、輸出国、輸入国、機械出荷日、設置日、エンドユーザー、NCモデルID、工作機械ID、契約ID、契約者ID、販売ID、機械代理店ID、機械代理店住所ID、出荷ID、エンドユーザーID、設置先住所ID、設置ID

実データや顧客名を含む元CSVはこの成果物に同梱していません。

## 検索仕様

- 主要項目の横断検索・全列検索・列指定検索
- 空白区切りの複数語をAND（すべて）／OR（いずれか）で検索
- `M800V AND X1001`、`X1001 OR X1003` のような式に対応（演算子の大文字・小文字は不問）
- ANDをORより優先。`(M800V OR M800W) AND メーカー` のように括弧で順序を指定
- `"Test Manufacturer"` は空白を含めて1語として検索。演算子自体を探す場合も `"OR"` のように引用符で囲む
- 空白の結合方法は画面のAND／OR選択に従い、明示した演算子が優先。各語は選択した検索対象内の異なる列にも一致可能
- 不正な検索式はエラー表示し、直前の検索結果を保持
- 全角/半角、大文字/小文字、かな/カナ、空白/記号の正規化
- 前方一致・部分一致と限定的な編集距離候補検索（あいまいモード）
- シリアル番号・ID・番号の編集距離による自動同一視は禁止（近似候補は識別子として表示しない）
- ヒットしたすべての行はページングで閲覧可能。行選択で元CSVの33項目を表示
- 検索処理はWeb Workerで実施し、描画は1ページ20～100件に制限
- 非空でないCSVヘッダーや列数の不一致を検知
- UTF-8／CP932を自動判定

**注意**：類似度スコアは便宜的な検索優先度です。機械の同一性・名寄せの判定には使わないでください。GDH原本の正規化・統合・照合機能を置き換えません。

## GDH自動取得に必要な作業

`GDH_INTEGRATION.md` を参照してください。`gdh-export.js` と `gdh-embed.js` をGDH側で読み込み、現在の検索フォームを `sourceForm` として渡します。提供HTMLで確認した既存出力処理を使い、セッションを引き継いでCSV Blobを取得します。正式な配置と本番での動作確認は別途必要です。

## セキュリティ

- 読み込んだCSVの原本はサーバーへ送信せず、ブラウザWorker内で処理
- localStorage / IndexedDBへデータを保存しない
- 外部CDN・API・ライブラリへの依存なし
- GitHubや公開サイトに実CSVをアップロードしない
- GDH連携時も元の認証・権限・監査ルールを維持する

## 開発用簡易テスト

`node tests/smoke.cjs` を実行します。検証用の架空データのみを使用します。元のMVP資料には実CSV 192,836件の解析成功の記録があります。v1.1.0リリース後、referenceに追加された実CSVでも192,836件の読込、AND／OR検索、最終ページ、33項目の詳細表示を検証しました。実CSVは配布アーカイブから除外します。Edge 156でローカルHTMLの動作を確認し、架空データ192,836件・約62MBで読込約3秒、識別子検索約4秒を測定しました（単一環境での参考値）。確認範囲は `RELEASE_CHECKLIST.md` を参照してください。

## GDHの追加画面として表示

`index.html?embedded=1` またはiframe内ではブランドヘッダーを省いた埋め込み表示になります。同一オリジンで配置した `gdh-embed.js` の `mountCncMachineViewer` で既存の表示領域に追加できます。v1.2.0では `gdh-export.js` も読み込み、`sourceForm` にGDH機械情報検索画面の `#frmmain` を渡すとデータ取得を接続できます。配置URLとGDHの画面登録手順は管理者の仕様に合わせます。詳細は `GDH_INTEGRATION.md` を参照してください。

## ブラウザ回帰テスト（開発者向け）

`tests/browser.cjs` は開発用Playwrightが解決可能な環境で `node tests/browser.cjs` として実行します。`TEST_BROWSER_CHANNEL=msedge` でインストール済みEdgeを指定できます。Playwrightはアプリの実行には不要です。ローカルHTMLと、テスト専用の127.0.0.1サーバーで埋め込み・親画面の架空CSV受け渡しを確認します。GDH本番にはアクセスしません。
