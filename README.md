# CNC機械情報ビューア（v1.0.0）

GDHの機械情報CSVをローカルブラウザで読み込み、約19万件規模の機械情報を検索・詳細確認できる単一HTMLアプリです。

## 起動方法

`index.html` を Microsoft Edge / Google Chrome で開きます。開発サーバー、npm、外部CDNは不要です。

- **現在動作する機能**：「CSVを開く」→ GDHから取得済みのCSVを選択 → 検索・閲覧
- **GDH接続後に動作する機能**：「データ取得」→ GDHの正規CSV出力処理でBlobを取得 → 同一CSVをダウンロード → 検索元データへ自動反映

ブラウザ標準のセキュリティ制約のため、独立したローカルHTMLからGDHサイトの確認ダイアログを勝手に押したり、別サイトのCSVダウンロード内容を読み取ることはできません。**GDHに実在するAPI・拡張機構は未確認**なので、架空のURLに接続しません。GDH連携は `window.GDH_CSV_EXPORT_ADAPTER` を通じて実装する契約です。

## 入力CSVの実測構成（2026-11-02のユーザー提供CSV）

- 192,836行 / 33列 / 約57MB
- UTF-8 BOM付き
- ヘッダー: NCシリアル番号、NCシリーズ名、NCシステム型名、工作機械シリアル番号、工作機械モデル番号、機械メーカー、サービス拠点、契約番号、契約タイプ、契約期間（月）、契約開始日、契約終了日、契約元拠点、契約者名、販売日、販売会社、機械代理店、輸出国、輸入国、機械出荷日、設置日、エンドユーザー、NCモデルID、工作機械ID、契約ID、契約者ID、販売ID、機械代理店ID、機械代理店住所ID、出荷ID、エンドユーザーID、設置先住所ID、設置ID

実データや顧客名を含む元CSVはこの成果物に同梱していません。

## 検索仕様

- 主要項目の横断検索・全列検索・列指定検索
- 全角/半角、大文字/小文字、かな/カナ、空白/記号の正規化
- 前方一致・部分一致と限定的な編集距離候補検索（あいまいモード）
- シリアル番号・ID・番号の編集距離による自動同一視は禁止（近似候補は識別子として表示しない）
- ヒットしたすべての行はページングで閲覧可能。行選択で元CSVの33項目を表示
- 検索処理はWeb Workerで実施し、描画は1ページ20～100件に制限
- 非空でないCSVヘッダーや列数の不一致を検知
- UTF-8／CP932を自動判定

**注意**：類似度スコアは便宜的な検索優先度です。機械の同一性・名寄せの判定には使わないでください。GDH原本の正規化・統合・照合機能を置き換えません。

## GDH自動取得に必要な作業

`GDH_INTEGRATION.md` を参照してください。GDHの出力APIの呼び出し方式、セッション、CSV Blob取得を確認し、同一オリジンで動くGDH拡張画面または許可された連携コードから実装します。

## セキュリティ

- 読み込んだCSVの原本はサーバーへ送信せず、ブラウザWorker内で処理
- localStorage / IndexedDBへデータを保存しない
- 外部CDN・API・ライブラリへの依存なし
- GitHubや公開サイトに実CSVをアップロードしない
- GDH連携時も元の認証・権限・監査ルールを維持する

## 開発用簡易テスト

`node tests/smoke.cjs` を実行します。検証用の架空データのみを使用します。元のMVP資料には実CSV 192,836件の解析成功の記録があります。今回のリリースでは実CSVは提供されておらず、再検証していません。Edge 156でローカルHTMLの動作を確認し、架空データ192,836件・約62MBで読込約3秒、識別子検索約4秒を測定しました（単一環境での参考値）。確認範囲は `RELEASE_CHECKLIST.md` を参照してください。
